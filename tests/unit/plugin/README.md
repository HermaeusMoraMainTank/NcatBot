# Plugin Mixin 模块测试

源码模块: `ncatbot.plugin.mixin`

## 验证规范

### ConfigMixin (`test_config_mixin.py`)

| 规范 ID | 说明 | 验证点 |
|---------|------|--------|
| M-01 | `_mixin_load()` | 从 YAML 文件加载配置 |
| M-02 | `set_config()` | 设置配置项后立即持久化 |
| M-03 | `get_config(key, default)` | key 不存在时返回默认值 |
| M-04 | `remove_config()` | 移除配置项，返回 `bool` |
| M-05 | `update_config()` | 批量更新多个配置项 |
| M-06 | 配置文件不存在 | 优雅返回空字典 |

### DataMixin (`test_data_mixin.py`)

| 规范 ID | 说明 | 验证点 |
|---------|------|--------|
| M-10 | `_mixin_load()` | 从 JSON 文件加载数据 |
| M-11 | `_mixin_unload()` | 将数据保存到 JSON |
| M-12 | 数据文件不存在 | 优雅返回空字典 |

### EventMixin (`test_event_mixin.py`)

| 规范 ID | 说明 | 验证点 |
|---------|------|--------|
| M-20 | `events()` | 返回 EventStream 并追踪到 `_active_streams` |
| M-21 | `wait_event(timeout)` | 超时抛出 `TimeoutError` |
| M-22 | `_mixin_unload()` | 关闭所有活跃 stream |
| M-23 | `wait_group_message_event()` | 类型过滤与 predicate 返回可回复的群消息实体 |
| M-24 | `wait_private_message_event()` | 忽略群消息并返回可回复的私聊消息实体 |

### TimeTaskMixin (`test_time_task_mixin.py`)

| 规范 ID | 说明 | 验证点 |
|---------|------|--------|

| M-31 | `remove_scheduled_task` | 服务可用时返回 `True` |

### RBACMixin (`test_rbac_mixin.py`)

| 规范 ID | 说明 | 验证点 |

### Import Dedup (`test_init_import_dedup.py`)

| 规范 ID | 说明 | 验证点 |
|---------|------|--------|
| ID-01 | `__init__.py` 导入不导致双重 exec | `from .main import X` 不会导致 handler 重复注册 |
| ID-02 | 无 `__init__` 导入时行为不变 | `load_module` 复用已导入模块，pending 数量正确 |

### PluginLoader 生命周期 (`test_plugin_loader.py`)

| 规范 ID | 说明 | 验证点 |
|---------|------|--------|
| LD-01 | `load_plugin` 成功 | handler flush 到 dispatcher |
| LD-02 | `load_plugin` 异常 | handler 清理回滚 |
| LD-03 | `unload_plugin` | handler revoke + on_close |
| LD-04 | `load_all` 拓扑排序 | 按依赖顺序加载 |
| LD-05 | 缺失依赖跳过 | 跳过缺依赖的插件，继续加载其他 |
| LD-06 | `_instantiate` 注入元数据 | name/version/author/description 正确注入 |
| LD-07 | 热重载失败后重试 | reload 失败后再次文件变更仍应尝试加载 |
| LD-08 | 运行时新插件自动索引 | 新放入的插件目录自动索引并加载 |

### McFish 钓鱼规则 (`test_mcfish_rules.py`, `test_mcfish_robbery.py`)

| 规范 ID | 说明 | 验证点 |
|---|---|---|
| MCF-01 | 鱼竿掉落等级限制 | 只能获得自身、低级或下一等级鱼竿 |
| MCF-02 | 原鱼竿绝对概率保留 | 越级区间转为空竿，不重分配到低级鱼竿 |
| MCF-03 | 碎片兑换鱼竿 | 合成命令可在没有材料时直接消耗碎片获得鱼竿 |
| MCF-04 | 概率明细同步 | 不可越级的鱼竿显示为 0 概率 |
| MCF-05 | 概率图片数据分栏 | 分别生成当前用户栏和全部鱼竿栏 |
| MCF-06 | 概率图片渲染 | 生成双栏 PNG 图片 |
| MCF-07 | 概率命令发送图片 | `钓鱼概率` 发送图片消息 |
| MCF-08 | 鱼竿掉落随机属性 | 钓到鱼竿后进入鱼竿背包并生成随机耐久、维修和附魔 |
| MCF-09 | 合成来源询问 | 碎片和鱼竿材料都足够时先询问合成方式 |
| MCF-10 | 选择鱼竿合成 | 选择鱼竿材料时不扣除碎片并继续合成 |
| MCF-11 | 合成来源选择未确认 | 取消、超时、无效回复或未明确选择时不消耗碎片和鱼竿 |
| MCF-12 | 真实会话选择鱼竿合成 | 回复“2”时使用鱼竿材料而不是优先消耗碎片 |
| MCF-13 | 纯文本反馈图片化 | 正式插件事件的纯文本回复发送为图片 |
| MCF-14 | 结果文本图片化 | 消息数组中的文本段发送为图片并保留图片段 |
| MCF-15 | 合成耐久按比例 | 零耐久材料不能直接合成满耐久鱼竿 |
| MCF-16 | 合成耐久随机 | 合成耐久在材料比例的随机区间内变化 |
| MCF-17 | 掉落鱼竿随机属性 | 掉落鱼竿的属性在对应鱼竿范围内随机 |
| MCF-18 | 帮助图分区布局 | 生成 1600px 宽且高度受控的双栏帮助图 |
| MCF-19 | 其他图片卡片布局 | 背包、商店、图鉴、概率、时钟和结果图使用统一的标题栏、浅色背景与卡片分区 |
| MCF-20 | 消耗品按竿使用 | 装备消耗品按配置 uses 转为剩余竿数，并在每竿结算时扣除一次 |
| MCF-21 | 消耗品进度展示 | 背包图片显示激活消耗品的剩余次数和进度条 |
| MCF-22 | 鱼竿卡片布局 | 鱼竿双行属性保持在背包卡片内，不覆盖下一格 |
| MCF-23 | 任务进度同步 | 一次行为同时推进每日和每周任务，进度封顶 |
| MCF-24 | 任务周期刷新 | 跨日/跨周自动清空任务进度和领取标记 |
| MCF-25 | 经济手续费曲线 | 维修与合成手续费随鱼竿等级递增并受维修上限约束 |
| MCF-26 | 任务领取幂等 | 每日/每周混合奖励只发放一次 |
| MCF-27 | 任务池分档 | 任务板按简单/中等/复杂和等级档位组合任务，奖励包含经验、金币、碎片或物品 |
| MCF-28 | 鱼获任务交付 | 领取命令一次性检查并扣除指定鱼获，鱼获不足不扣除且不发奖励 |
| MCF-29 | 任务池编号选择 | 领取命令按任务板编号路由，不会误操作其他任务 |
| MCF-30 | 等级档位边界 | 玩家等级跨过5/10/20/30后，任务板切换到对应等级池 |
| MCF-31 | 任务展示库存进度 | 任务展示读取背包鱼获，不提前修改任务进度或背包 |
| MCF-32 | 任务板操作文案 | 顶部只显示一次领取指令，不在每个任务重复操作提示 |
| MCF-33 | 任务周期显示 | 任务板显示每日月日和每周起止月日，不显示年份和具体时间 |
| MCF-34 | 合成材料缺口 | 碎片不足时显示已有数量、目标数量和缺口 |
| MCF-35 | 装备材料缺口 | 装备碎片不足时显示已有数量、目标数量和缺口 |
| MCF-36 | 多路线材料缺口 | 碎片和鱼竿材料都不足时分别显示两条路线的材料缺口 |
| MCF-37 | 饰品合成帮助 | 帮助明确装备合成指令、碎片/手续费、效果和消耗品启用方式 |
| MCF-38 | 饰品合成手续费 | 饰品和消耗品使用按当前经济分布重新设定的金币手续费 |
