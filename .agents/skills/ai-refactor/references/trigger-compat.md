# Phase 1 · 触发规则与现有命令兼容

> 原则：**命令与查询优先于状态机**；状态机只接管「要不要 AI 闲聊回复」。

---

## 1. 处理顺序（目标）

```text
1. 群白名单？否 → return
2. 排除插件命令 / meme 关键词 / 点歌点播引导回复？是 → return（可不入账或入账但不分析）
3. 管理特殊：回复「撤回」等 → return
4. 精确/包含命令表匹配？是 → 执行命令，不走分析员
5. 冻结用户？是 → 仅允许「查印象」类已约定查询；其它 return
6. 消息入账 context
7. determine 状态 → 分析员 / 发送 …
```

---

## 2. 现有命令兼容表

| 用户输入（现状） | 行为 | 改造后 |
|------------------|------|--------|
| `蓝晴说话` | 强制走 AI（管理/白名单群） | **保留**；等价强制 `SUMMONED` + 可跳过分析员直接专家（或分析员必 true） |
| `查询余额` | DeepSeek 余额 | **保留**；不入状态机决策 |
| `蓝晴印象` / `蓝晴印象 @某人` | 查印象 | **保留**；冻结用户仍可查自己相关规则维持现状 |
| `蓝晴知识库` | 知识库统计 | **保留** |
| `蓝晴好感度排行榜` / `蓝晴好感度排行` | 排行图 | **保留** |
| 纯文本 `测试` + 图 | 视觉测试 | **保留** |
| `@机器人` 或含「蓝晴」 | 主动 AI | → `SUMMONED` |
| 普通群聊 | 原 8% 被动 | → 仅 `FAMILIAR` 或过渡 fallback；**终态无裸 8%** |
| `meme` / memeKeys 关键词 | 排除 | **保留排除** |
| 其它插件代发 | `add_plugin_sent_reply` | **保留入账**；`source` 标记继续 |

唤醒别名：配置化 `aliases`；默认包含「蓝晴」。含别名但属于上表命令句时，**命令优先**（如「蓝晴印象」不走进聊天生成）。

---

## 3. 触发源 → 状态映射

| 触发源 | 目标状态 | 备注 |
|--------|----------|------|
| CQ `@` 机器人 QQ | `SUMMONED` | 扫描「上次 AI 回复之后」任意一条含 @ |
| 文本别名（非命令） | `SUMMONED` | 看最新一条用户消息 |
| 复读达标 | `FAMILIAR` | 仅从 `NOT_PRESENT` |
| 密集达标 | `FAMILIAR` | 仅从 `NOT_PRESENT` |
| 蓝晴说话 | 强制回复路径 | 可记为 `SUMMONED` + `force` |
| 观测期普通消息 | 留在 `OBSERVATION` | 只入账 |
| 观测期唤醒 | `SUMMONED` | 打断 |

---

## 4. CD / 观测与命令

| 场景 | 群 CD | 观测期 |
|------|-------|--------|
| 查询类命令 | 不占用 | 不改变 |
| 强制「蓝晴说话」 | 建议占用 | 回后进观测 |
| 正常 AI 回复 | 占用 | 进观测 |
| 分析员否决 | 不占用（推荐） | 不变 |

---

## 5. 回调 `enable_callback`（现状默认关）

改造后：**默认仍关闭**。若开启，语义为「AI 刚回过某人 → 短时间其下一条非 @ 消息可再触发一次」——与 `OBSERVATION` 冲突时，**以 OBSERVATION 为准**（回调视为历史兼容，实现阶段建议废弃或并入「对某人的短观察例外」）。Phase 1 文档标记为 **legacy，不优先设计**。
