# Phase 2 · 记忆行为预览（请确认）

> 在 Phase 1 交互之上的记忆层体验。确认后 Phase 2 文档可关单。

---

### 功能 1：自动带一点相关记忆（不刷屏）

专家回复前静默 recall，用户无感「查库」。

**对话流**：
```text
用户A: 蓝晴 今天吃啥
（系统 recall → 命中「用户A不吃香菜」）
蓝晴: 火锅？我让他们少放香菜
```

---

### 功能 2：用户要求记住 → remember

**对话流**：
```text
用户A: 蓝晴记住，我之后都叫你小晴
蓝晴: 好，那我记下来了
（工具 remember: judgment=用户A希望被称呼为「小晴称呼蓝晴为小晴」, scope=user:A, type=preference）
```

---

### 功能 3：短知识，不灌长文

**对话流**：
```text
用户B: 蓝晴 宫保鸡丁咋做
（知识库仅注入 ≤100 字卡片 ×≤3）
蓝晴: （按卡片简述步骤，不贴八百字攻略）
```

---

### 功能 4：印象 / 好感命令不变

**对话流**：
```text
用户A: 蓝晴印象
蓝晴: （仍走 user_impression 卡片，含好感档位）

用户A: 蓝晴好感度排行
蓝晴: （排行图照旧）
```

---

### 功能 5：不记单次废话

**对话流**：
```text
用户C: 我现在下楼买奶茶
（不调用 remember；不当长期记忆）
蓝晴: 顺便帮我带杯草莓的～
```

---

### 功能 6：巩固对用户不可见

后台降低废记忆 strength / 软删；用户侧无「系统正在睡眠」提示（除非管理命令）。

---

## 确认清单

- [ ] 自动 recall 注入可以
- [ ] remember 仅在明确「记住」/长期事实时
- [ ] 知识短条目 + 注入上限
- [ ] 印象/好感命令不动
- [ ] 暂不做 note 读写工具

请回复 **「记忆预览 OK」** 或指出修改。
