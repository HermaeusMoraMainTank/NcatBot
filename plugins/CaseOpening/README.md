# CaseOpening · CS2 开箱 + Dota 2 开瓶

一个插件两个玩法模块：`cs2.py`（CS2 武器箱）与 `dota.py`（Dota 2 宝瓶），
共享经济、借贷、图片缓存与卡片渲染。以后加抽卡只要再挂一个模块。

- `开箱帮助` / `开瓶帮助` / `箱子帮助` / `cs帮助` / `dota帮助` **返回同一张说明图**（开箱帮助会主动截断事件，不会被钓鱼插件接走）
- 指令前缀区分：`cs…` 与 `dota…`
- 借贷共用一份账本：`data/case_loan/loan.db`
- 经济走 `GroupEconomy`，**1 元 = 200 金币**

## CS2 开箱（`cs…`）

| 指令 | 作用 |
|---|---|
| `cs箱子 [页码]` | 箱子列表：编号、中文名、箱价、每次开箱成本 |
| `cs详情 <箱子\|编号>` | 内容分档、概率、钥匙、价格 |
| `cs价值表 <箱子\|编号> [页]` | 单箱价值表：每件带图与回收价区间 |
| `cs开箱 <箱子\|编号> [1-10]` | 买入并立刻开箱 |
| `cs背包 [页码]` | 物品网格（3 列 × 5 行），按价格从高到低 |
| `cs物品 <序号>` | 外观 / 磨损值 / 市场名 / 回收价 |
| `cs出售 <序号\|all>` | 按市价 ×0.85 回收，所得优先还贷 |
| `cs汰换 <序号×10\|1-10\|军规>` | 汰换合同：10 件 → 下一档 1 件 |
| `cs汰换预览 <同上>` | 配方与出货概率，不执行 |
| `cs查价 <关键词>` | 查 Skinport 挂单价 |
| `cs战绩` / `cs榜` | 个人统计 / 开箱榜 |

## Dota 2 宝瓶（`dota…`）

| 指令 | 作用 |
|---|---|
| `dota宝瓶 [页码]` | 宝瓶列表：图标、中文名、国服售价 |
| `dota详情 <名字\|编号>` | 内容分层、递增概率、累计奖励 |
| `dota开瓶 <名字\|编号> [1-10]` | 买入并立刻开瓶 |
| `dota一轮 <名字\|编号>` | 本轮各档第几次、下次概率、还差几瓶必出 |
| `dota饰品 [页码]` | 饰品网格，按价格排序 |
| `dota卖 <序号>` | 出售可上架物品（无交易锁），所得优先还贷 |
| `dota战绩` / `dota榜` | 个人统计 / 开瓶榜 |

13 个宝瓶（2024–2026，均可在游戏内购买），售价 ¥17 / ¥21 / ¥35。

## 序号规则

背包与饰品都按**当前回收价从高到低**排，卡片角标 `#1` `#2`… 就是**你自己的**序号，
跨页连续。`物品 / 出售 / 汰换 / dota卖` 都只认这个序号。

## 开箱贷

| 规则 | 说明 |
|---|---|
| 借钱 | `借钱 <金额>` 或 `借款 <金额>` |
| 额度 | 单次最多 **1,000,000** 金币 |
| 频率 | **同时只能欠一笔**：上一笔没还清不能再借；还清或重生后可再借，**没有每日次数限制** |
| 用途 | 只能用于开箱/开瓶，不能提现 |
| 扣费顺序 | 先用额度，再扣钱包 |
| 还款 | `还款 <金额>` 或 `还钱 <金额>`；出售所得优先自动还贷 |
| 还不起 | `重生` → 60 秒内 `重生 确认` → **自动变卖背包物品抵扣欠款**、两边背包清空、余额与剩余欠款清零（钓鱼等其它插件不受影响）；结果卡会写「本次欠款 / 累计欠款」的金币与人民币 |

`借贷` 查看：可用额度、欠款、钱包余额、今天能否再借，
以及历史留痕——累计欠款 / 已还 / 最高欠款 / 借款次数 / 重生次数 / 上次重生日期。
每次借用、还款、重生都写进 `loan_log`。

## 配置

`config.py`：

| 键 | 默认 | 说明 |
|---|---|---|
| `coin_per_cny` | 200 | 1 元换多少金币 |
| `sell_fee` | 0.15 | 回收手续费 |
| `key_price_usd` / `usd_cny` | 2.49 / 7.2 | 钥匙折算 |
| `page_size` | 15 | 背包/饰品每页 |
| `cs2_max_batch` | 10 | CS2 单次上限（无每日上限） |
| `dota_max_batch` | 10 | Dota 单次上限（无每日上限） |

## 数据

- 快照：`plugins/common/case_data/data/*.json.gz`（20 箱 + 2126 皮肤 + 13 瓶）
- 重建：`python scripts/build_case_data.py`
- CS2 箱子/皮肤中文名来自 ByMykel `zh-CN` 数据集
- Dota 套装名暂无中文源，可用 `data/CaseOpening/dota/names_cn.json`（`{"英文名":"中文名"}`）覆盖

运行态（不进版本库）：

- 物品图缓存 `data/CaseOpening/**/images/`：启动时补下箱子/宝瓶图标，物品图首次渲染时按需下载；下坏的文件会自动删除重下
- 指令卡片 `data/CaseOpening/**/cards/`：每小时清理一次，只保留最近 1 小时的图
- 图片缓存每天清理一次：超过 30 天或超过 3000 张时回收最旧的

> 改 `plugins/common/case_data/` 下任何文件后必须**重启**机器人——热重载不会重载共享模块。
