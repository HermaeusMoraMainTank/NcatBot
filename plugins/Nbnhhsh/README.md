# Nbnhhsh 插件

## 功能描述

这是一个基于"能不能好好说话"（nbnhhsh）API的翻译插件，用于将网络缩写词翻译成中文。

## 使用方法

在群聊中发送以下格式的消息：

```
翻译 要翻译的内容
```

例如：
- `翻译 今天天气真好，但是tmd太热了`
- `翻译 这个API很好用，但是需要处理JSON数据`
- `翻译 我用了HTTP请求获取数据`

## 功能特点

1. **自动识别缩写词**：自动提取文本中的字母数字组合（2个字符以上）
2. **在线翻译**：调用 nbnhhsh API 获取翻译结果
3. **结果缓存**：避免重复请求相同缩写词
4. **格式化输出**：清晰显示翻译结果，包括来源说明

## 输出格式

- ✅ 有翻译结果：显示翻译内容
- 🤔 有猜测结果：显示可能的含义
- ❓ 无结果：显示"暂无翻译"
- ❌ 翻译失败：显示错误信息

## 技术实现

- 使用 `https://lab.magiconch.com/api/nbnhhsh/` API
- 支持正则表达式提取缩写词
- 异步处理，不阻塞其他功能
- 错误处理和日志记录

## 注意事项

- 需要网络连接才能正常工作
- API 请求可能有时延，请耐心等待
- 某些缩写词可能没有对应的翻译
