# PrivateReminder

独立的时间预约与私聊提醒插件，不依赖 McFish。

## 命令

```text
预约 21:30 收鱼
预约 明天 08:00 起床
预约 11-05 21:30 收鱼
预约 2026-11-05 21:30 收鱼
预约 30分钟 喝水
预约 2小时 休息
预约 21:30

预约列表
我的预约
取消预约 3
取消预约 全部
预约帮助
```

- 时间按 `Asia/Shanghai` 计算，可在 `config.yaml` 修改。
- 省略日期时：今天未到就今天，已过就明天。
- 提醒内容可省略，默认发送“时间到了”。
- 群聊中创建的预约也会通过私聊发送；创建时会尝试发送一条私聊确认，失败会在群内提示。
- 私聊发送失败会自动重试 3 次，仍失败则标记为发送失败。
- 最多同时保留 20 条待发送预约，时间范围最多 365 天。

## 配置

```yaml
timezone: Asia/Shanghai
check_interval: 20s
max_pending: 20
max_content_length: 200
max_horizon_days: 365
```

预约数据保存在插件运行目录的 `data.json`，重启后继续生效；机器人离线期间到期的预约会在下次启动后补发。

## 管理后台

统一管理后台新增「预约提醒」页：

- 查看全部用户的任务、预约时间、剩余时间、重试次数与失败原因
- 手动取消任意任务
- 页面每 15 秒自动刷新，也可手动刷新
