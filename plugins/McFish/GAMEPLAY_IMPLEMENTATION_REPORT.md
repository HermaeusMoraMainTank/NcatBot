# McFish 玩法改造实施报告

> 实施日期：2026-09-15
>
> 本报告记录本轮已完成的开发内容、数值依据和与改造前的差异。

## 1. 实施范围

本轮选择了低打扰、可持续验证的两项改造：

1. 建立按难度和钓鱼等级分档的任务池，由每日/每周任务板排列组合生成任务。
2. 增加按具体鱼种和数量定义的任务，并拆分查看、指定编号交付、指定编号领取入口。
3. 把维修和合成接入 GroupEconomy，形成稳定的金币支出点。

没有加入自由市场、偷鱼、电鱼、赌博、抽卡或新的货币，避免一次改动改变太多经济变量。

## 2. 前后对比

| 方面 | 改造前 | 改造后 |
|---|---|---|
| 任务系统 | 没有 McFish 任务 | 从任务池抽取每日 3 项、每周 4 项，另有 1 项永久鱼王收集任务，保存周期快照 |
| 任务分档 | 无 | 简单/中等/复杂；1-5、5-10、10-20、20-30、30+级 |
| 任务选择 | 不适用 | 任务板编号化；领取可指定编号，低档任务不领取即可跳过 |
| 每日任务 | 无 | 1 个低档简单任务 + 当前等级中等/复杂任务 |
| 每周任务 | 无 | 1 个低档简单任务 + 当前等级中等/复杂任务 + 当前等级消费任务 |
| 维修 | 同名鱼竿材料 | 同名鱼竿材料 + 20–600 金币手续费 |
| 鱼竿/装备合成 | 碎片或材料 | 原材料不变 + 按目标和批次数收取手续费；商店购买鱼竿不作为材料 |
| 经济账本 | 购买和出售已有流水 | 新增 `mcfish_repair`、`mcfish_craft`、任务奖励流水 |
| 老玩家数据 | 只有原有状态字段 | 任务字段按首次访问懒创建，跨周期自动刷新 |

## 3. 任务规则与奖励

### 任务池和生成规则

任务池条目包含任务目标、任务类型、难度、等级档位、每日/每周数量和对应奖励。当前等级使用以下档位：

| 档位 | 适用等级 | 设计方向 |
|---|---:|---|
| 简单 | 每个等级档位 | 少量基础鱼，奖励经验、少量金币或返还基础鱼 |
| 中等 | 每个等级档位 | 混合鱼种，奖励更多经验、金币、碎片或消耗品 |
| 复杂 | 每个等级档位 | 大量基础鱼或多鱼种订单，奖励净化书和高级消耗品 |

每日任务板保留一个 1-5 级简单任务，让玩家可以主动选择是否接低档订单；另外两个任务从当前等级的中等、复杂池中抽取。每周任务再增加一个当前等级的金币消费任务。任务在周期首次生成时保存快照，玩家中途升级不会改变已生成的目标；同一周期内允许抽到相同类型的任务，但任务类型加具体要求（鱼种/金币及数量）必须不同。旧存档检测到重复任务时会自动替换重复槽位，并保留仍能匹配的进度和领取状态。

### 每日任务

| 任务池示例 | 目标 | 奖励 |
|---|---:|---:|
| 1-5 级简单 | 交付鳕鱼 6 条 | 经验 20 + 鳕鱼 10 条 |
| 11-20 级中等 | 交付鳕鱼 25 条 + 鲑鱼 10 条 | 经验 220 + 100 金币 + 14 碎片 |
| 11-20 级复杂 | 交付鳕鱼 40 条 + 鲑鱼 20 条 | 经验 350 + 净化书 1 本 + 金竿 1 根 |

具体条目由任务池按周期排列组合，任务板会显示实际鱼种和数量，不再出现无对象的“交付鱼获 0/5”。

### 常驻任务

钓鱼等级达到 35 级后，任务板才显示“鱼王全收集”常驻任务。任务要求成功获得 `FISH_KINGS` 中的全部 8 条鱼王各 1 次，进度读取玩家 `king_stats` 中的成功捕获记录，不读取当前背包数量，因此鱼王被出售、消耗或不在背包中都不会影响已经完成的收集进度。领取时不扣除鱼王，且任务只能领取一次；奖励是一根不可损坏的三叉戟，耐久归零后可直接支付金币修复，不需要同名鱼竿。

### 每周任务

| 任务池示例 | 目标 | 奖励 |
|---|---:|---:|
| 1-5 级简单 | 交付鲑鱼 12 条 | 经验 80 + 120 金币 |
| 11-20 级中等 | 交付鳕鱼 75 条 + 鲑鱼 30 条 | 经验 650 + 320 金币 + 35 碎片 |
| 11-20 级复杂 | 交付鳕鱼 100 条 + 鲑鱼 50 条 | 经验 1000 + 净化书 2 本 |
| 11-20 级消费 | 消费金币 1200 | 经验 260 + 16 碎片 + 隐秘诱饵 1 个 |

任务奖励不自动发放。领取任务时才会检查交付鱼获：背包满足全部要求就一次性扣除任务要求数量并发放奖励；鱼获不足则本次领取失败，不扣鱼、不保存部分进度，也不发奖励。任务板展示交付任务时读取背包真实数量，例如要求 6 条且持有 10 条时显示 `鳕鱼 10/6`，查看不会改变状态。每日周期显示月日，每周周期显示起止日期范围，均不显示年份和具体时间。低档任务不领取即可跳过。非交付类任务进度仍按目标封顶，避免重复操作超额膨胀。

## 4. 手续费曲线

维修费公式为：

```text
min(600, max(20, 鱼竿均价 / 10 + 缺失耐久 / 10))
```

因此低等级鱼竿的维护成本不会阻断新玩家，高等级鱼竿的长期收益会有持续回收。合成手续费如下：

| 操作 | 手续费基准 |
|---|---:|
| 碎片兑换鱼竿 | `max(20, 碎片成本 / 3)` |
| 三根材料合成鱼竿 | `max(20, 目标鱼竿均价 / 10)`，按合成组数累计 |
| 财富浮标 | 30000 金币 |
| 坚韧钓组 | 50000 金币 |
| 黄金磁石 | 80000 金币 |
| 幸运海星 | 120000 金币 |
| 魔法鱼饵 | 100 金币 |
| 隐秘诱饵 | 160 金币 |
| 万能鱼饵 | 220 金币 |

手续费在材料消耗前检查余额并扣款。鱼竿合成失败仍只扣该次手续费，不会额外重复扣款；余额不足时材料保持不变。使用碎片兑换鱼竿时，即使没有上一等级鱼竿，也必须先确认是否消耗碎片；取消、超时或无效回复都不会扣除资源。合成材料不足时，回复会按可用合成路线列出已有数量、目标数量和缺口，便于直接判断应补充碎片还是鱼竿材料。

饰品和消耗品均通过明确的 `合成xxx` 命令制作：永久饰品合成后使用 `装备xxx` 装备，默认2格；钓鱼等级10级支付80个碎片解锁第3格，20级支付180个碎片解锁第4格，最多4格。永久饰品使用 `升级xxx` 消耗碎片升至Ⅲ级，升级不消耗金币；使用 `卸下xxx` 或确认 `卸下全部饰品` 可取消装备，同名永久饰品不能重复装备。旧存档中的永久饰品自动视为Ⅰ级，不追溯扣除碎片。消耗品合成后也使用 `装备xxx` 启用，装备时从背包移除1个并转换为对应竿数，每完成一竿消耗1次。新的金币手续费按当前存档的金币分布和钓鱼出售净流入重新拉开档位，本轮仅将永久饰品按上一版手续费的100倍调整，消耗品保持原有100/160/220金币档位；帮助中列出了各装备的碎片成本、手续费、效果和消耗品使用次数；只影响后续升级和合成，不追溯已完成的合成。

槽位和升级数值如下：

| 内容 | 条件/Ⅰ→Ⅱ | 消耗碎片 | Ⅱ→Ⅲ | 消耗碎片 |
|---|---|---:|---|---:|
| 第3个饰品槽位 | 钓鱼等级10级 | 80 | - | - |
| 第4个饰品槽位 | 钓鱼等级20级 | 180 | - | - |
| 财富浮标 | - | 60 | - | 120 |
| 坚韧钓组 | - | 80 | - | 160 |
| 黄金磁石 | - | 110 | - | 220 |
| 幸运海星 | - | 150 | - | 300 |

一级饰品合成成本保持财富浮标120、坚韧钓组160、黄金磁石220、幸运海星300个碎片不变。饰品Ⅰ/Ⅱ/Ⅲ级效果分别为：财富浮标宝藏×1.35/1.50/1.65、鱼王咬钩×1.20/1.28/1.36；坚韧钓组鱼王上钩率+12/16/20个百分点；黄金磁石宝藏品质+1/2/3档、宝藏售价×1.25/1.35/1.50、普通鱼售价×1.08/1.12/1.16、鱼王售价×10/30/100；幸运海星普通碎片概率16%/20%/24%。普通鱼售价加成不作用于隐藏鱼和鱼王，鱼王售价加成同时作用于钓起显示价和出售结算价，出售时保留每条捕获鱼王按长度计算的基准售价。

## 5. 逻辑一致性检查

- 任务奖励按任务档位匹配：低档以经验、基础金币和返还鱼为主，中档加入钓鱼碎片与消耗品，高档加入净化书。任务奖励不自动发放，且只有玩家指定提交订单时才会消耗鱼获。
- 每周“装备养护”要求至少消费 1200 金币，且只统计成功的 GroupEconomy 扣款，不会因为余额不足或取消交互推进。
- 维修手续费最低 20 金币，低于常见鱼获售价；最高 600 金币，避免高等级鱼竿因耐久缺口产生无限高价。
- 任务奖励以碎片为主，金币奖励只占日常任务的一部分，不直接提高鱼获出售价格。
- 达到鱼竿使用等级后，商店常驻出售铁竿、金竿、钻石竿、下界合金竿，价格为 540/900/1260/1620 金币；商店购买杆标记为不可合成，出售时按固定购买价计算并经过出售税，掉落、任务奖励、碎片兑换和合成杆不受影响。常驻附魔道具为诱钓 500 金币（每日 5 个）和海之眷顾 1000 金币（每日 3 个），附魔书不参与每日价格波动。
- 鱼竿可通过 `分解鱼竿` 或 `分解铁竿` 等命令回收为碎片，返还数量按木竿 1、铁竿 2、金竿 4、钻石竿 8、下界合金竿 16、三叉戟 32 递增；分解前需要选择并确认，当前装备不会被分解。
- 附魔书使用前会检查对应等级是否已满；满 3 级不消耗道具，未满时成功率为严格 50%。维修时的附魔继承概率保持独立的 50% 规则。
- 任务状态保存在现有玩家 JSON 中，不新增钱包或第二套账本；旧玩家在首次访问时自动补齐每日、每周和常驻任务字段。常驻任务不会随日期刷新。
- 后台逐竿结算仍通过现有增量合并保存，任务进度随每竿结算一并落盘。

## 6. 使用方式

```text
钓鱼任务
领取钓鱼任务 3
```

任务无需接取。每日/每周任务板在周期开始时从任务池生成并保存；钓鱼等级达到35级后才显示常驻鱼王全收集任务。发送 `领取钓鱼任务 编号` 后，系统会检查指定任务：普通交付任务会扣除鱼获，常驻鱼王任务只检查历史成功捕获记录，不扣除鱼王。条件满足后发放奖励，未满足时不改变状态。不填编号的领取命令会依次处理当前已满足条件的任务。
