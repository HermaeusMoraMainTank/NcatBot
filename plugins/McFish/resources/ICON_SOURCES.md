# 图标来源

`resources/*.png` 是 McFish 的物品图标，按物品中文名直接命名，`_item_image` 会按名字查找。
`resources/icons/*.png` 是项目自设内容的图标，通过 `asset_id` 映射，清单见 `asset_manifest.json`。

## 护核纪元 WIKI

- 装备、首饰、贵重品、材料、食物、钥匙、箱子、神谕卡片、鱼王鳞片与上古遗物碎片
  均取自 [护核纪元 CoreKeeper WIKI](https://wiki.biligame.com/hhjy/) 的对应条目。
- 钓鱼页面用于材料、食物、贵重品、钥匙、箱子、鱼王鳞片与上古遗物碎片；
  防具 / 头盔 / 胸甲 / 腿甲页面用于护甲；项链 / 戒指页面用于首饰；
  神谕卡片页面用于九张卡片；鱼饵页面用于三种消耗品与财富浮标。
  磁铁与金色海星用于黄金磁石和幸运海星。
- 上锁的灿阳金属箱子使用 wiki 的 `上了锁的灿阳金属箱子` 原始图标。

- `深海黑鳍` 使用墨鱼图标，`深海灯笼鱼` 使用热带鱼图标。
- `遗迹铜鳞` 使用鹦鹉螺图标，`遗迹金鳞鱼` 使用鲑鱼图标。
- `风暴幼龙` 使用河豚图标，`风暴海龙` 使用鳕鱼图标。
- `钓鱼碎片` 使用 Prismarine Shard 贴图。
- `坚韧钓组` 使用 Fishing Rod 贴图。

## 项目自绘

- 8 条限时鱼王的技能提示与文字仍为项目内容；图标已改为 wiki / FF14 / Minecraft 鱼类图标。
- 财富浮标、黄金磁石、幸运海星、魔法鱼饵、隐秘诱饵、万能鱼饵使用护核纪元鱼饵/磁铁/海星图标。
- 其余未列出的项目图标为历史资源。
