# McFish

移植自 `FloatTech/ZeroBot-Plugin` 的 Minecraft 钓鱼模拟器。

## 帮助

发送 `钓鱼帮助` 或 `查看钓鱼规则` 查看完整规则和命令。兼容单独发送 `钓鱼`，等价于 `进行钓鱼`。

帮助图片末尾的“已确认的特殊机制”由 `MCFISH_SPECIAL_MECHANICS` 渲染，覆盖美西螈（每竿吃 3 条鱼、非鱼竿物品一次 5 个、不消耗耐久、鱼不够时永久离开）、海豚、鱼数超过 100、净化书保底、宝藏诅咒、每日交易上限、半价福利以及修复/附魔/合成细节。

## 命令

`钓鱼背包`、`钓鱼商店`、`钓鱼看板`、`钓鱼时钟`、`钓鱼图鉴`、`进行钓鱼`、`进行N次钓鱼`、`购买物品`、`出售物品`、`出售所有垃圾`、`装备鱼竿`、`装备财富浮标`、`装备魔法鱼饵`、`修复鱼竿`、`附魔诱钓`、`附魔海之眷顾`、`合成鱼竿`、`合成财富浮标`、`合成魔法鱼饵`、`消除宝藏诅咒`、`当前装备概率明细`。

新装备只能使用钓鱼碎片合成，不能从普通钓鱼结果直接获得。永久饰品成本为：财富浮标 120、坚韧钓组 160、黄金磁石 220、幸运海星 300；消耗品成本为：魔法鱼饵 24（10竿）、隐秘诱饵 42（6竿）、万能鱼饵 50（5竿）。普通碎片掉落为 8% 的 1–2 个，个人连续 12 次未获得时第 13 次保底；另有 0.1% 概率触发碎片宝藏，额外获得 50 个。

合成规则与原插件一致：成品耐久固定为成品满耐久（木竿 30、铁竿 50、金竿 70、钻石竿 100、下界合金竿 150、三叉戟 301）、维修固定为 0，诱钓与眷顾取三根材料附魔等级的向下取整平均值；材料自身的耐久与维修不继承，所以拿 3 根干净材料合成出来的属性每次都一样。每次合成有 10% 概率失败并销毁材料，“梭哈”按每 3 根一组分别计算属性。

鱼王窗口由每周持久化的非整点时间表生成，全部位于 09:00–21:00，前后置窗口有重合但每组时长约 23–47 分钟。`钓鱼时钟`只在查询时发送图片，展示当前状态和最近 5 次鱼王窗口，绝不创建主动通知任务。`进行N次钓鱼`会为每竿生成独立且按顺序递增的隐藏上钩时间，普通鱼最低约 30 秒且时间随鱼种和随机波动变化，因此只有虚拟时间落在窗口内的竿才有鱼王机会。

钓鱼结束后会显示本次经验总计，以及每一竿的上钩时间、结果和该竿经验。

鱼王的路径、技能和概率详见 [FISH_KING_GUIDE.md](FISH_KING_GUIDE.md)。

钓鱼结果会先在后台立即生成并保存，再按照隐藏上钩时间延迟发送。等待时间按鱼种计算并带随机波动：低级鱼约 30 秒起，高级普通鱼和鱼王更慢；鱼竿附魔和鱼饵仍会影响最终等待时间。同一玩家在任务完成前再次钓鱼会收到稍后重试提示，其他玩家仍可正常操作。钓鱼指令支持阿拉伯数字和常用中文数量，例如 `进行十次钓鱼`。

背包、商店和看板按原插件使用图片输出。

掉落数量与原插件一致：背包中鱼的总数量超过 100 条时，掉落大类区间切换为 2/8/35/45，只改变概率不改变数量；只有装备美西螈时，非鱼竿物品才会一次获得 5 个（鱼竿与美西螈本身仍为 1 个）。
