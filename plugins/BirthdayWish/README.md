# 生日祝福插件 (BirthdayWish)

这是一个生日祝福插件，可以管理群成员的生日信息并发送生日祝福。

## 功能特性

1. **获取群成员信息** - 调用API获取群友信息并输出到控制台
2. **设置生日** - 用户可以设置自己的生日
3. **查询生日** - 用户可以查询自己设置的生日
4. **生日祝福** - 发送生日祝福消息
5. **配置文件管理** - 自动保存和加载生日数据

## 命令列表

### 基础命令
- `生日检查` - 获取群成员信息并输出到控制台
- `生日快乐` - 发送生日祝福消息

### 生日管理命令
- `设置生日 MM-DD` - 设置自己的生日（例如：设置生日 12-25）
- `我的生日` - 查询自己设置的生日

### 成员信息查询
- `成员信息 @用户` - 查询指定成员的详细信息

## 配置文件

插件会在 `data/BirthdayWish/BirthdayWish.json` 中保存以下数据：

```json
{
  "birthday_data": {
    "群号": {
      "用户QQ": "MM-DD"
    }
  },
  "settings": {
    "auto_check": true,
    "check_time": "09:00",
    "blessing_messages": [
      "生日快乐！愿你所有的梦想都能实现！",
      "祝你生日快乐！愿你的每一天都充满阳光和快乐！"
    ]
  }
}
```

## 开发说明

这个插件目前是基础框架，主要功能包括：

1. **API调用示例** - 展示了如何调用获取群成员信息的API
2. **控制台输出** - 将群成员信息输出到控制台，方便开发时查看
3. **基础功能** - 提供了生日设置、查询等基础功能

你可以基于这个框架继续开发更多功能，比如：
- 自动生日提醒
- 生日蛋糕图片生成
- 生日统计功能
- 生日祝福卡片
- 等等

## 使用方法

1. 将插件放入 `plugins/` 目录
2. 重启机器人
3. 在群聊中使用相关命令

## 注意事项

- 生日格式必须为 MM-DD（例如：12-25）
- 生日数据按群组分别存储
- 配置文件会自动创建和管理
