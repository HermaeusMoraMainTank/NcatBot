# Robbery

移植自 `FloatTech/ZeroBot-Plugin` 的群友钱包打劫功能。

## 命令

- `打劫 @用户`
- `打劫 QQ号`

发起者和目标余额都至少为 1000 才能发起打劫；成功率为 40%；失败时随机赔偿目标 1 到本次潜在抢劫金额 50% 之间的金币；成功获得对方 0% 到 5% 加 500 的财产，最高 10000；每日可打劫或被打劫一次，失败不计入次数。

## 后台测试账号配置

插件支持通过 `test_user_profiles` 配置仅后台生效的测试账号参数。测试账号配置不会出现在普通用户消息中：

- `victim_success_rate`：目标被成功抢劫的概率；
- `stolen_balance_ratio`：按目标余额计算的可抢金额比例，另加原有的 500 金币基础值；
- `loss_stolen_ratio`：目标实际损失占潜在抢劫金额的比例；
- `robbery_failure_rate`：该账号发起抢劫时的失败率。

默认测试配置为账号 `10123121`：被抢成功率 60%、金额比例 10%、实际损失比例 10%、抢劫失败率 75%，并通过 `is_test_account` 标记。未命中测试账号时，使用本页前述生产默认规则。
