# YmNsfwPy NSFW检测插件

## 简介
YmNsfwPy是一个基于nsfwpy的群聊NSFW内容检测插件，可以自动检测群聊中的不当内容并通知管理员。

## 主要功能
- 自动NSFW内容检测
- 管理员权限管理
- 通知人管理
- 阈值设置
- 模型切换
- 配置管理

## 帮助功能
输入 `nsfw` 即可查看完整的命令帮助图片，包含所有可用命令的详细说明。

## 命令分类

### 管理员管理（仅全局管理员）
- `添加管理员 @用户` - 添加群组管理员
- `移除管理员 @用户` - 移除群组管理员
- `查看管理员` - 查看管理员列表

### 通知人管理
- `添加通知人 @用户` - 添加NSFW检测通知人（管理员可用）
- `移除通知人 @用户` - 移除NSFW检测通知人（管理员可用）
- `查看通知人` - 查看通知人列表（仅全局管理员）

### 开关控制
- `开启nsfw检测` - 开启本群NSFW检测（管理员可用）
- `关闭nsfw检测` - 关闭本群NSFW检测（管理员可用）

### 阈值设置
- `设置全局阈值 0.x` - 设置全局检测阈值（仅全局管理员）
- `设置阈值 0.x` - 设置本群检测阈值（管理员可用）
- `重置阈值` - 重置本群阈值使用全局阈值（管理员可用）
- `查看阈值` - 查看当前检测阈值

### 模型设置
- `切换模型 d/m2/i3` - 切换检测模型（仅全局管理员）

### 配置管理
- `刷新配置` - 手动刷新配置（仅全局管理员）
- `保存配置` - 手动保存配置（仅全局管理员）

### 其他功能
- `测试` - 测试插件是否正常工作
- `debug` - 查看调试信息（仅全局管理员）

## 权限说明
- **全局管理员**：拥有所有权限，可以管理其他管理员、设置全局参数
- **群组管理员**：拥有部分管理权限，可以管理通知人、开关检测、设置群组阈值
